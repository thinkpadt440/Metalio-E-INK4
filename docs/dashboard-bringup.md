# Dashboard 第一阶段固件

版本：`0.1.1-dashboard`，基于官方 `2.0.63`，ESP-IDF `v5.5.4`。
板型：Metalio E-Ink4 3.97 寸、ESP32-S3、16MB Flash；界面使用 480×800 竖屏。

## 当前行为

- 工作台采用两列指标卡片：token 速率（含瞬时、开机以来峰值）、生成 token（含上下文、TTFT、使用率、耗时）、推理任务（含总槽位）、显存占用。
- 当前没有接入指标数据源，显示 `--`；不会把参考图中的数字当作真实数据。
  `DashboardScreen::UpdateMetrics()` 为后续网络适配层提供线程安全的快照入口。
- GPU 状态未知时显示“待检测”；上报无显存时隐藏显存卡片，并拓宽任务卡片。
- 移除大时钟以容纳指标，顶栏继续显示设备时间、电池和网络图标。
- 助手标题合并为“助手（未连接）”“助手（准备录音）”或“助手（录音中）”。
- 助手去掉触摸上一页/下一页按钮，内容宽度扩至 448px，文本直接从标题下方开始。
  演示文本与返回主页按钮保留在底部，页码位于两者之间。
- 音量+ / 音量-、盖板 PREV/NEXT 翻页，首页/末页不会越界。
- 工作台短按 BOOT 进入助手；长按超过 500ms 进入助手并继续录音（需仍按住）。
  助手页长按 BOOT 开始录音、松手停止，短按不再切换演示文本。
- 录音复用现有 AudioService 输入任务，采集 16kHz、16bit 单声道 PCM，最多 30 秒。
  仅保留最近一次录音在 PSRAM，新录音覆盖旧录音，重启后丢失；没有 ASR 或上传。
  录完显示实际采样时长，服务未连接时明确显示尚未发送。
- 松手发生在音频初始化之前或过程中、离开助手、进入待机、满 30 秒时都会结束/取消录音。
  录音期间占用本地麦克风及禁止自动待机的需求，结束后释放；不会开启原厂聊天连接。
- HOME 返回工作台。POWER 短按待机、长按关机，仍使用原来的电源管理。
- 设置入口保留，用于配网、电源、日志和硬件诊断。旧桌面主题不改变新工作台布局。

原有应用源码和部分启动/待机服务仍保留用于渐进迁移。
Wi-Fi/4G 沿用设备现有配置，不自动切换或覆盖凭据。

## 构建与烧录

```bash
cd /home/sven/proj/eink4
. /home/sven/esp/esp-idf/export.sh
idf.py build
```

已刷过本项目原版、分区及字体资源一致时，验证这版可只烧应用：

```bash
idf.py -p /dev/ttyACM0 app-flash monitor
```

首次刷机或资源不一致时使用 `idf.py -p /dev/ttyACM0 flash monitor` 完整烧录。
`build/Metalio-E-Ink4.bin` 是应用镜像，不应当作完整镜像写到 `0x0`。
完整合并镜像放在 `build/firmware/`，相应地址为 `0x0`。

## 真机验收

1. 开机进入四块指标工作台，确认数字未接入时为 `--`，顶栏电量/网络正常。
2. 短按 BOOT 进入助手；检查标题内联状态、阅读区域、底部没有触摸翻页按钮。
3. 点击演示文本，用音量键逐页读到 1/3、2/3、3/3，首尾多按不得越界。
4. 助手中长按 BOOT 约 2 秒并说话，松手后应显示接近实际采样的时长。
   日志应出现 `local recording started` 与结束样本数、非零峰值。
5. 从主页直接长按 BOOT 不松，确认进入助手后开始录音；松开应停止。
6. 快速松手、按 HOME 离页、POWER 待机，检查录音停止；再次进入可正常重新录音。
7. 验证录音到 30 秒自动停止，音频启动失败时展示失败而不是假装录音成功。
8. 在工作台和助手各测试 POWER 待机/唤醒，页面恢复且可继续操作。
9. 检查无 panic、watchdog、异常重启；必要时唤醒并重接 USB 后重新 attach WSL。

离线检查使用实际页面、PTT 控制器和 PCM 缓冲代码，但模拟麦克风输入、硬件状态和主任务调度。
已覆盖初始化前/中松手、启动失败、输入失败、30 秒上限、离页/待机取消、峰值/无 GPU 布局、
分页边界和 60 次页面往返。离线通过不能代替麦克风、音质、刷屏及休眠唤醒的真机验收。
运行方法见 `tools/ui_preview/README.md`。
