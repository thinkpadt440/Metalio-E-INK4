# Dashboard 第一阶段固件

版本：`0.1.0-dashboard`，基于官方 `2.0.63`，ESP-IDF `v5.5.4`。
板型：Metalio E-Ink4 3.97 寸、ESP32-S3、16MB Flash；界面使用 480×800 竖屏。

## 当前行为

- 开机和 HOME 统一进入新工作台，显示本地时间、日期、网络类型和连接状态。
- 顶栏复用真实电池、网络图标和通知；未有有效时间时显示 `00:00` 和“时间待同步”。
- 设备网络连接成功不代表助手服务已连接；助手始终明确显示“尚未连接服务”。
- 点击“进入助手”或在工作台长按 BOOT 打开新助手，不启动旧语音会话。
- 助手先显示空页面，点击“演示文本”或短按 BOOT 载入三页固定文本。
- 上一页/下一页触摸按钮、盖板 PREV/NEXT，以及音量+ / 音量-可翻页。
  首页/末页不会越界；长按音量键不会在助手内改变音量。
- 点击“返回主页”或盖板 HOME 返回工作台。
- POWER 短按待机、长按关机，仍使用原来的电源管理。
- 设置入口继续使用现有设置页，用于网络配置、电源、日志和硬件诊断。
  设置中的旧桌面主题不会改变新工作台布局。

本阶段不连接 harness、不录音、不发出聊天请求。原有应用源码和部分启动/待机服务
仍保留用于渐进式迁移；这还不是精简完旧业务的最终固件。
Wi-Fi/4G 继续沿用设备现有配置，不自动切换或覆盖凭据。

## 构建与烧录

```bash
cd /home/sven/proj/eink4
. /home/sven/esp/esp-idf/export.sh
idf.py build
```

已刷过本项目原版、分区及字体资源一致时，验证这版可只烧应用：

```bash
idf.py -p /dev/ttyACM0 app-flash monitor
```

首次刷机或资源不一致时使用 `idf.py -p /dev/ttyACM0 flash monitor` 完整烧录。
`build/Metalio-E-Ink4.bin` 是应用镜像，不应当作完整镜像写到 `0x0`。
完整合并镜像放在 `build/firmware/`，相应地址为 `0x0`。

## 真机验收

1. 冷启动进入工作台，检查所有文字完整、时间和电量显示、网络状态约 5 秒更新。
2. 分别用触摸“进入助手”和长按 BOOT 进入，确认没有进入旧的百问/小智页面。
3. 点击演示文本，依次翻到 1/3、2/3、3/3；首尾多按几次，不得越界。
4. 验证触摸按钮、盖板键及音量键翻页，点击重读应回到 1/3。
5. 使用返回按钮和 HOME 回主页，反复往返并进入设置检查配网入口仍可用。
6. 在主页和助手页各测试一次 POWER 待机/唤醒，确认页面恢复且可继续操作。
7. 检查日志无 panic、watchdog、异常重启；必要时退出待机并重接 USB 后重新 attach WSL。

离线预览检查方法见 `tools/ui_preview/README.md`。离线通过不代替以上真机验收。
