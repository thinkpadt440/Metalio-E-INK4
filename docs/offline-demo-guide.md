# Metalio E-Ink4 脱机演示指南

版本：0.1.4。当前 feature/dashboard 保留为领导演示分支。真实后端开发分支 feature/companion 已在开始演示修改前，从 6729fdb 创建；其中不包含本次演示脚本。

## 演示内容

本版本可脱离后端演示。Dashboard 显示预设的合理使用数据，全部/30天/7天会切换统计。会话列表只有“日常闲聊”和“编码助手”。界面不再显示演示标识或脚本说明；语音后的转写、助手回复、代码修改、检查和构建结果均为预设脚本，不进行真实 ASR、调用模型、修改项目或执行命令。实际麦克风仍用于 BOOT 录音及状态展示。

模型和授权选项按会话独立保存，返回首页再进入仍保留。聊天记录最多保留每会话十屏；点击“重置测试”或重启恢复初始内容。Dashboard 消息/Token 计数随脚本对话递增，为演示数据，不是实时服务统计。

## 推荐演示顺序

1. 首页展示六项统计，点击30天、7天、全部，展示使用概览。
2. 进入助手，选择日常闲聊。可用音量键或盖板键翻阅已有对话。
3. 长按 BOOT 约1–2秒并松开：本地录音后，约1秒回显预设用户文本，再约2秒给出闲聊回复。任意语音都走同一演示脚本，不会识别实际说话内容。
4. 返回会话列表，选择编码助手，确认默认授权为“完全访问”，模型为 DeepSeek V4.1-Pro（底部简写 V4.1-Pro），另一选项为 DeepSeek V4.1-Flash。
5. 点击底部授权级别，选择“请求审批”。约2秒后出现审批确认；等待期间显示分析中。
6. 点击 HOME 右边两个盖板键中左边那个，模拟批准；或点击屏幕“仅本次允许”。接着显示继续修改，约2秒后检查中，再约2秒后完成。
7. 再打开授权级别并选择“请求审批”，可重复审批场景。此次点击右边盖板键或屏幕“拒绝”，展示拒绝后的停止结果，不会继续执行。
8. 若要展示完全访问无需审批：选择“完全访问”，长按 BOOT 录音后松开，预设编码任务会直接走分析、修改、检查、完成。

## 按键与复位

| 操作 | 效果 |
|---|---|
| 首页短按 BOOT | 打开两个会话的选择页 |
| 首页/会话列表长按 BOOT | 进入日常闲聊并录音 |
| 聊天页长按 BOOT、松开 | 基于当前会话启动预设演示对话；处理过程中不启动第二段录音 |
| 普通聊天页音量+ / 音量- | 上一屏 / 下一屏 |
| 审批时 HOME 右侧两键的左键 | 通过，仅本次允许；底层键名 vk_prev |
| 审批时 HOME 右侧两键的右键 | 拒绝；底层键名 vk_next |
| 审批时 BOOT | 不录音、不批准 |
| 会话列表“重置测试” | 恢复数据、模型、授权和聊天初始内容，可反复演示 |
| POWER | 沿用原有手动待机/唤醒/关机 |

注意：现有音量键也分发 vk_prev/vk_next，所以审批确认页中音量+等同左键通过，音量-等同右键拒绝；该页无长详情翻页。演示审批请优先按盖板键或屏幕按钮。为保持演示过程，Dashboard/助手显示期间通过现有 StandbyInhibit 接口阻止自动息屏，离开页面会释放；没有改电源策略默认设置。

## 构建与烧录

在 WSL 中执行：

~~~bash
cd /home/sven/proj/eink4
. /home/sven/esp/esp-idf/export.sh
idf.py build
idf.py -p /dev/ttyACM0 app-flash monitor
~~~

烧录前确认 USB 已附加到 WSL、端口存在。仅已使用兼容分区与字体资源时用 app-flash；不需要因为离线演示重新写分区。桌面副本 firmware/Metalio-E-Ink4-offline-demo.bin 同样是应用镜像，不能直接写到0x0。

## 检查范围

主机预览使用真实页面、字体、录音控制器和演示状态机；检查两秒审批、按键方向、批准/拒绝、完全访问、预设闲聊、重复操作、历史上限、60次页面往返和布局边界。ESP-IDF 构建验证应用尺寸和链接。

真实盖板键、麦克风、屏幕刷新延迟、手动待机/唤醒仍须刷机后现场确认。审批两秒指脚本触发时点，墨水屏刷新需要额外时间。
